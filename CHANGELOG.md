# Changelog

## 2.1 — 2026

- Interface translated to English: new file `guaitaMDeditor_v2.1_en.html`. The Catalan file is `guaitaMDeditor_v2.1.html`.
- Same functionality as 2.0 in both languages.
- LaTeX export uses `babel` with the interface language.

## 2.0 — 2026

- Word-style ribbon and drop-down menus (File, Edit, View, Insert, Format, Paragraph, Table, Tools, Help).
- Editable formatted view (WYSIWYG) with two-way Markdown synchronisation.
- Outline and paragraphs side panel; move and promote/demote sections.
- Editable tables with context menu and Tab navigation.
- Delimited-data importer with preview (delimiter detection, sorting, transposition, deduplication).
- Own undo/redo stack shared by both views.
- `==highlight==` and footnote extensions, with a one-time notice.
- Exports to `.md`, `.html`, LaTeX and `.txt`; print to PDF.
- Caixetí dark theme (default) and light theme; system fonts.
