guaita.MDeditor 2.1

A Word-style Markdown editor in a single HTML file. Write in a formatted page, get clean Markdown, export to Markdown, HTML, LaTeX or text. Part of the Guaita Apps suite.

Open the editor Català Download

What it does

  • Visual editing (WYSIWYG) of Markdown, with a code pane kept in sync.
  • Dual view: formatted page, Markdown source, or both side by side.
  • Ribbon and drop-down menus similar to a word processor.
  • Outline and paragraphs panel: move and promote/demote whole sections.
  • Editable tables with a context menu and Tab navigation.
  • Delimited-data importer (CSV, TSV and other delimiters) with preview, sorting and transposition.
  • Highlight and footnotes as Markdown extensions.
  • Exports to .md, .html, LaTeX and .txt; print to PDF.
  • Own undo stack shared by both views; autosave of the session.

Requirements and language

Any modern browser. Works offline: everything is inside the file. The interface is available in English and Catalan.
